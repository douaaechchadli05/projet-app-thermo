# Calculateur Loi de Raoult - Version Légère

## Installation rapide
1. Installez les dépendances:
   ```
   pip install -r requirements.txt
   ```

2. Lancez l'application:
   ```
   python app_new.py
   ```

## Accès
- URL: http://127.0.0.1:5000
- Login: admin / admin

## Fonctionnalités
- Calculs thermodynamiques (Loi de Raoult)
- Authentification sécurisée
- Historique personnel
- Design moderne bleu/vert

## Structure minimale
- `app_new.py` - Application principale
- `requirements.txt` - Dépendances
- `templates/` - Pages HTML modernes
